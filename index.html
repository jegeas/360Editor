Bienvenido al Editor 360

Para quitar y añadir elementos, el editor usa la IA de Google Gemini con tu propia API key. Solo hay que ponerla una vez:

  1. Entra en aistudio.google.com/apikey con tu cuenta de Google.
  2. Pulsa Crear clave de API y cópiala.
  3. Pégala aquí abajo.

Los modelos de imagen de Gemini son de pago: el proyecto de esa clave necesita facturación o saldo activos.

Ajustes

Tu clave se guarda solo en este ordenador (archivo config.json), nunca se sube a GitHub y solo se envía a Google.
